# GxSan 优化方案：从「看数据」到「给建议」

> 版本：2026-08-05 更新（标记阶段一已完成 + 架构变更同步）
> 触发：用户普通用户视角 Top10 需求 + 3 条吐槽 + 总结论

---

## 0. 背景与核心论断

用户原始诉求（普通用户视角）：

** Top5（最想要）**
1. **Dashboard 总览** —— 一眼看清"我的退休金进度到哪了"
2. **行动提示** —— 明确告诉我"现在该买 / 卖 / 等"，别只给数据
3. **分红到账记录** —— 真实到账的历史，而不只是"计划分红"
4. **持仓成本一键修正** —— 分红除权后成本自动下调（或一键手动）
5. **导出** —— 数据能导出来（CSV / Excel）

** Top5（其次）**
6. 股价走势图（历史价格 + 估值带）
7. 回测（策略历史表现）
8. 多设备同步（云同步 config）
9. 股利日历提醒（哪天除权、哪天到账，提前提醒）
10. 暗色模式

** 3 条吐槽**
- 数据太散，找不到重点
- 术语太多，看不懂
- 没有"下一步该干嘛"

** 总结论（用户原话）**
> 从"看数据"到"给建议"，是这个工具最大的体验跃迁空间。

## 1. 产品定位重定

| | 旧定位 | 新定位 |
|---|---|---|
| 一句话 | 分红数据浏览器 | 个人分红养老操盘助手 |
| 用户每次打开得到 | 一堆指标 | 一个明确的"下一步动作" |
| 核心问题 | 我持有啥、赚多少 | 我现在该干嘛、离目标还差多少 |

> 所有新功能都应服务于"降低决策门槛"：把已有的信号/估值/网格，**翻译成人话指令**。

## 2. 分阶段路线图

### 阶段一（建议引擎 MVP） — ✅ 已完成（2026-08-04，提交 343ac71 + 2bc6275）

> 目标：把已有的 `strategy.DividendStrategy` + 网格，变成用户能直接照做的指令。复用度最高、成本最低、价值最大。

**1.1 Dashboard 总览页 ✅**
- 退休金进度条：当前年化分红 ÷ 目标年分红×12 → 进度 %
- 四张核心卡：总资产 / 年化分红 / 目标年分红 / 进度百分比
- 行动提示汇总（BUY/HOLD/WATCH/SELL 计数）
- 行动提示明细表（按优先级排序，含股息率/建议金额/数量/理由）
- 底部"推荐关注"入口，链接到跟踪推荐页

**1.2 行动提示（Action Advisor） ✅**
- 对每只持仓输出 `买 / 卖 / 持有` + 建议金额或股数 + 一句话理由
- BUY 估算股数 = 金额÷现价，向下取整到 100 股（A 股整手）
- SELL 估算金额 = 卖出股数×现价
- 在 Dashboard 与 Portfolio 两个页面展示
- 数据契约：`model.ActionAdvice{ Action, SuggestedBuyAmount, SuggestedBuyShares, SuggestedSellShares, SuggestedSellAmount, Reason, Constraint, Priority, CostCorrectable }`

**1.3 持仓成本一键修正 ✅**
- `CorrectHoldingCost(code, totalCost)`：以真实投入总额推导精确每股成本（总价÷股数）
- 首次修正时保存 `OriginalCost` 快照（原始买入成本，防止分红除权后看不到当初买入价）
- Portfolio 编辑弹窗增加"真实投入总额"输入框 + "原始买入成本"只读展示
- 成本显示精度从 2 位小数放开到 4 位（`fmtCost()` 最多 4 位去尾零）

### 阶段二（现金流真实化） — 待启动

**2.1 分红到账记录（真实历史）**
- 现有 `GetDividendHistory` 是"每股分红预案"，不是"我实际到账"
- 需新增：按 `持仓股数 × 每股 × 到账日` 计算真实到账金额，落盘到 `data/` 或 config 的 `received_dividends`
- 视图：时间线/列表 + 累计已收分红 + 年化实现率（实际 ÷ 计划）

**2.2 股利日历 + 提醒**
- 抓取除权除息日、股权登记日、派息日（EastMoney 相关接口可扩展）
- 日历视图 + 提前 N 天本地提醒（系统通知 / 桌面托盘，Wails 支持）
- 依赖：2.1 的到账数据结构

---

### 阶段三（可读性与可携带）

**3.1 导出 CSV / Excel**
- 持仓、分红汇总、到账记录均可导出
- 后端新增 `GetExport(kind)` 返回 CSV 字符串；前端下载（Wails 用系统文件对话框）

**3.2 暗色模式**
- 前端已用 CSS 变量（`--text-muted` 等），加主题切换 + 持久化到 `localStorage`
- 实现成本很低，对长时间看盘用户感知度高

**3.3 术语降噪 ✅ 已完成**
- 全站文案审查：`YoC` → "成本股息率"、估值带 → "低估/合理/高估阈值"、信号 → "建议买入/卖出/持有/关注中"
- 信号键名（BUY/SELL/HOLD/WATCH）仅作内部标识符，经 signal.js 翻译后显示中文
- 前端用户可见文案已全部中文，无英文缩写残留

---

### 阶段四（深度与多端，按需）

**4.1 股价走势图 + 估值带**
- 前端引入轻量图表（ECharts / Chart.js），叠加 cheap/fair/expensive 三条线 + 历史价格 + 分红标记
- 依赖：行情接口需补历史 K 线（当前 `EnrichStock` 只有即时价 + PE/PB）

**4.2 回测**
- 对选定股票/策略，用历史分红 + 价格模拟"如果 X 年前开始定投，现在收益"
- 复用 `plan/compound` + 历史数据

**4.3 多设备同步**
- `config.yaml` 同步到云（GitHub Gist / 自建 / OneDrive）
- 含持仓成本属敏感数据，需加密或仅放用户私有仓库
- 最小可行：导出/导入 + 手动同步；进阶：自动 push 到私有 gist

## 3. 架构变更记录（2026-08-05）

| 变更 | 说明 | 影响 |
|------|------|------|
| 合并双层目录为单一 module | 原 `gxsan/gxsan/`（GUI 子模块）已删除，GUI 代码提到根目录 | `main.go` 双入口：CLI 子命令 / Wails GUI |
| 删除 cmd/ 目录 | CLI 子命令内置到 `main.go` | 不再需要独立 cmd 入口 |
| 删除养老测算 GUI 页面 | Dashboard 退休金进度条已覆盖核心需求 | CLI 保留 pension 子命令，GUI 移除 /pension 路由和 GetPension 方法 |
| 删除资产转换 GUI 页面 | 功能使用频率低 | CLI 保留 compare 子命令，GUI 移除 /conversion 路由和 CompareStocks/RealEstateToEquity 方法 |
| 新增跟踪推荐页面 | 31 只推荐标的按 7 大分类展示 | 新增 /tracking 路由、Tracking.vue、tracking.go、GetTrackingStocks() 方法 |
| 缓存 TTL 市场感知 | 交易时段 3 分钟 / 非交易 8 小时（原固定 24h） | 修复现价不准问题 |
| Wails build tag 修复 | 必须加 `-tags production` | 修复双击 exe 弹错误窗的问题 |
