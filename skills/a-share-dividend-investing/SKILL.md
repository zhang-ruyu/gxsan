## 用户决策流程

拿到一个标的（或一笔新资金）后，按以下顺序决策：

```
1. 确认资金属性
   ├─ 不能亏的钱（养老/教育） → 只配弱周期红利，不碰周期/科技
   └─ 能亏完的钱（博弈/娱乐） → 可用牛市娱乐账户小仓位博弈

2. 计算静态股息率
   公式：上年度全年每股分红 ÷ 当前股价
   ├─ ≥5% → 攒股区间，积极低吸
   ├─ 4-4.5% → 合理区间，持有/等4.5%以上打底仓
   └─ <3.5% → 减仓区间，网格化减持

3. 检查分红趋势（近3年）
   ├─ 逐年递增 → 加仓优选
   ├─ 持平 → 继续持有
   ├─ 下滑一次有合理原因 → 观察，不急于操作
   └─ 连续下滑 → 红灯，考虑退出

4. 判断资产类型
   ├─ 弱周期红利（银行/水电/运营商） → 底仓长期不动
   └─ 顺周期红利（消费/有色/煤炭） → 小仓位立足收息，等周期反转

5. 设定网格参数
   ├─ 弱周期：攒股区5-7% → 合理区4-4.5% → 减仓区<3.5%
   └─ 顺周期：高景气期等6-7%股息率才具安全边际

6. 执行纪律
   ├─ 触发即执行，不纠结"还会不会跌/涨"
   ├─ 底仓不动，网格降本，分红100%复投（退休前）
   └─ 科技暴涨不分心——两套资金两套心理
```

### 端到端决策示例

**示例1：招商银行现在能买吗？**

```
1. 资金属性 → 养老账户（不能亏的钱）
2. 静态股息率 → 4.66%（当前约45元，上年度每股分红2.10元）
3. 分红趋势 → 近3年稳步递增 ✅
4. 资产类型 → 弱周期红利（银行），适合底仓
5. 区间判断 → 4-4.5%为合理区间，处于「持有/等4.5%以上打底仓」
6. 结论 → 等股价回调至46.6元以下（股息率≥4.5%），分批建底仓
   ├─ 现价可建10%试探仓
   ├─ 跌至~42元（≈5%）→ 加至20%
   └─ 跌至~38元（≈5.5%）→ 加至25%
```

**示例2：紫金矿业现在能买吗？**

```
1. 资金属性 → 养老账户（不能亏的钱）→ 顺周期仓位控制≤10%
2. 静态股息率 → ~2-3%（低），但成长性优秀、分红逐年增长
3. 分红趋势 → 近3年逐年递增 ✅
4. 资产类型 → 顺周期红利（金铜），不是底仓品种
5. 估值判断 → 2800亿市值≈金价3500对应12PE≈安全边际区
   网格：34→32→30→28→26→24，目标成本28元
6. 结论 → 当前30左右可建3-5成底仓（小仓位立足收息），
   预留现金等28-26-24分批低吸；底仓不动，不追高
```

**示例3：美的集团现在该卖吗？**

```
1. 当前状态 → 养老最大重仓（26.6%），成本61.5，浮盈丰厚
2. 事件评估 → 中报季+长鑫上市冲击→非弱周期红利可能承压
3. 操作判断 → 仓位最重+利润最厚→减仓压力最小
   ├─ 可逢高网格化减10-15%（如83+减1500股）
   ├─ 保留底仓85%+不动，长期收息
   └─ 中报确认+股价回调后买回
4. 性质 → 战术性风险对冲，非否定标的
```

**示例4：美的分红 10.34 万到账，怎么复投？**

```
1. 资金属性 → 分红再投资（养老账户），必须归位红利
2. 盘点当前各标的股息率 →
   ├─ 招行 5.5% → 攒股区间（≥4.5%），优先
   ├─ 移动 5.0% → 合理偏上，可小仓位低吸
   ├─ 紫金 30 元以下 → 有低吸机会
   ├─ 长电 ~3.7% → 合理区，不追
   └─ 神华 ~5-6% → 合理区偏下，可小仓位
3. 资金分配 → 60% 招行（股息率高+确定性最强）+ 40% 紫金（左侧网格低吸）
4. 若所有标的都在合理区以上 →
   └─ 现金放货基（如余额宝/逆回购），等中报季或回调再出手
   └─ "不让一分钱闲置"是对的，但更不要在合理价格以上追高
5. 核心原则 → 分红到账后宁可等一周等一个月，不急着复投；
   只低吸不追高，等股息率回到攒股区间再出手
```

## 攒股收息养老核心框架

### 核心理念：股权思维 vs 炒股思维

买股收息养老的本质是**股权投资思维**——你买入的是企业的一部分所有权。关注的不是股价，而是公司每年赚了多少钱、分给你多少钱。

| 维度 | 炒股思维 | 股权思维（攒股收息） |
|------|---------|-------------------|
| 赚钱方式 | 低买高卖赚差价 | 企业盈利 → 分红 → 复投 |
| 关注指标 | K线、成交量、消息面 | 每股分红、分红率、ROE |
| 波动态度 | 下跌=亏损、恐惧 | 下跌=打折加仓、攒更多股数 |
| 收益来源 | 不确定、依赖择时 | 确定的企业分红现金流 |
| 最终目标 | 卖在高点离场 | 终身持有、永续收息 |

**攒股收息的唯一公式：`股数 × 每股分红`**。

### 多账户体系

将资金按用途隔离到独立账户，各自目标、策略、风险偏好完全不同：

| 账户 | 用途 | 策略 | 资金属性 |
|------|------|------|---------|
| 养老账户 | 退休生活来源 | 红利核心仓+网格降本+行业分散 | 不能亏的钱 |
| 教育基金 | 子女教育费用 | 红利核心仓+打新+低波动优先 | 不能亏的钱 |
| 港美股账户 | 全球配置+超额收益 | 全球化分散+高成长+利润转A股红利 | 中等风险 |
| 娱乐账户 | 科技短线/博弈 | 科技趋势股+IPO博弈 | 极小仓位，能亏完的钱 |
| 打新账户 | 新股申购+配售 | 临时账户，达成即清仓 | 临时可调用的钱 |

**隔离的核心价值**：分红不被挪用、两套资金两套心理（不让科技暴涨暴跌动摇红利持股心态）、临时账户达成即归位。

### 生命周期四阶段

| 阶段 | 时间 | 核心任务 | 关键心理 |
|------|------|---------|---------|
| **启动期** | 1-3年 | 选好目标、坚持定投、养成复投习惯 | 熬住「看不出效果」的阶段 |
| **滚雪球期** | 3-8年 | 坚决不提现，分红100%复投；下跌加仓 | 忍住不卖、不花分红 |
| **自由期** | 8-15年 | 部分消费+部分复投，关注基本面 | 克制消费冲动 |
| **收获期** | 15年+ | 提取改善生活，其余复投，考虑传承 | 知足、不贪、安稳度过 |

### 成本股息率：核心指标

通过**低吸+网格降本**持续降低持仓成本后，你的**成本股息率**（每股分红 ÷ 你的持仓成本）会远超静态股息率。

💡 森哥实战：经过一年多低吸+网格化降本后——中海油负成本、美的/神华成本股息率7-8%。

> **核心路径**：静态股息率3-5% → 低吸+网格降本 → 成本股息率7-8% → 分红现金流质变 → "想亏钱都难"。

## 股息率概念

### 三种口径

| 类型 | 分子 | 确定性 |
|------|------|--------|
| **静态股息率** | 上一年度年报全年实际分红 | ✅ 100%确定 |
| **动态股息率** | 本年度中期+末期预估 | ⚠️ 含预测 |
| **滚动股息率(TTM)** | 最近4个季度实际分红 | 部分确定 |

### 选用建议：静态为主

- **静态（主力）**：年报季更新，财富保值要确定性
- **TTM（辅助）**：下半年修正，年报数据滞后半年时更"实时"
- **动态（忽略）**：卖方预估能否兑现未知

> 分母用查看当天的收盘价。任何文章给的静态股息率都是特定日期的快照，做买入决策时自己重新算。

### 历史分红维度

**3年平均静态股息率** = (近3年每股分红之和 / 3) / 当前股价

**每股分红趋势**比绝对值更重要：

| 趋势 | 含义 | 行动 |
|------|------|------|
| 逐年递增 | 最佳信号 | 加仓优选 |
| 持平 | 可接受 | 继续持有 |
| 下滑一次，有合理原因 | 需分析 | 观察 |
| 连续下滑 | 红灯 | 考虑退出 |

### A股分红周期与红利税

- 6-8月：年度分红高峰（部分银行一年两次）
- 持股>1年：股息红利税**0%（免税）**——分红复投天然匹配长期持有

## 标的比较框架

当用户问「A 和 B 哪个好」时，按下表逐维对比：

| 对比维度 | 说明 | 示例：招行 vs 移动 |
|---------|------|------------------|
| **当前股息率** | 静态，最近交易日 | 招行5.5% vs 移动4-5% |
| **3年平均股息率** | 平滑周期波动 | 招行稳定在5%+，移动近年提升 |
| **分红趋势** | 递增/持平/下滑 | 均为递增 ✅ |
| **波动性** | 弱周期（底仓）vs 顺周期（卫星） | 均为弱周期 ✅ |
| **流动性** | 日均成交额，进出是否方便 | 均高流动性 ✅ |
| **行业分散贡献** | 与现有持仓的相关性 | 招行→银行板块；移动→通信板块，互补 |
| **估值锚** | PE/PB 历史分位或特殊指标 | 招行PB<1；移动承诺≥75%分红 |
| **结论** | 综合判断 | 银行底仓优先招行；通信板块用移动补充，构成行业分散 |

## 筛选方法论

### 正面筛选（必要条件）

1. 连续分红年限 ≥5年（国企/银行优先）
2. 静态股息率 ≥3.5%
3. 分红比例 30%-70%
4. 近3年归母净利润无亏损
5. 近3年每股分红不下滑（或有合理原因）

- 分红金额超过当年归母净利润（透支式）
- 经营性现金流连续为负
- 资产负债率异常攀升
- 大股东高比例质押

### 加分项

- 央企/地方国企背景
- ROE >10%且稳定
- 每股分红逐年递增
- 一年两次分红

## 常见误区

### ❌ 错误1：只看静态股息率，不看分红趋势

股价暴跌→高股息率的背后可能是公司出问题了。必须结合近3年分红趋势、净利润走势综合判断。异常高的股息率（>8%）往往是陷阱。

### ❌ 错误2：在周期顶部重仓有色/煤炭

景气高点时股息率看似诱人，但周期下行后业绩和分红双双缩水。周期股高景气期要等**6-7%股息率**才具备安全边际，因为此时的"高股息"是用未来可能下滑的利润算出来的。

### ❌ 错误3：科技牛市中割红利追涨

两头挨打的经典操作。坚守账户隔离——红利的钱不能动，实在手痒用娱乐账户极小仓位博弈。

### ❌ 错误4：不区分"能亏的钱"和"不能亏的钱"

所有资金混在一个账户，科技暴跌时恐慌蔓延到红利持仓，导致底部割肉。必须物理隔离。

### ❌ 错误5：把分红当"免费的钱"

分红后股价会除息（下跌对应金额），短期总资产不变。分红的真正价值在于**长期复投**——用分红买入更多股数→下一次分红更多→股数再增加→复利效应兑现。这个过程需要**3-5年以上**才能明显感知。

## 森哥实战操作纪律

### 周期股左侧布局框架

💡 覆盖煤炭/石油/有色等周期红利品种的统一框架："高景气度+低股价=黄金坑"。

**三步走**：
1. **底仓**：估值合理区间建3-5成底仓，立足收息
2. **低吸**：大宗第一波杀跌后，网格化分批买入（如紫金28-26-24）
3. **收获**：运气好→反弹卖出获利；一般→完成建仓后立足收息等下一轮周期

**核心纪律**：
- 买之前就想好——了解企业和行业，预估各种情况，"机会来了信心满满迎接黄金坑，而不是手忙脚乱割肉"
- **底仓不要打太快**——最关键的教训：大仓位在27-28就打完了，真到26-24反而加得少
- 预留低吸仓位——跌下来有钱低吸，没钱就躺平立足收息等风来
- 知易行难——周期股剧烈波动超出预期是常态，保持心态稳定

### 买入原则

1. 只低吸、不追高：等回调、等恐慌、等"黄金坑"
2. 分批建仓：底仓3-5成，余下网格化分批
3. 大跌大买：市场恐慌时集中加码
4. 使用闲钱：卖出低效资产（如老破小房产）转换为红利股权

### 卖出原则

1. 股息率跌破合理区间 → 网格化减仓（非清仓）
2. 科技/IPO短线利润 → 全部转入红利
3. 基本面恶化 → 果断清仓
4. 同属性标的性价比切换（如神华→格力）
5. 保持平常心：涨了不狂喜，跌了不恐慌

### 事件驱动调仓

💡 根据日历事件提前调整仓位：
- **中报季避险**（7-8月）：提前降低非弱周期红利仓位，等业绩确认+回调后再买回
- **大型IPO冲击防御**：巨无霸上市前后大盘承压，非弱周期红利可能被拖累，提前减仓→事件后低吸回来
- **市场节奏**：科技-红利跷跷板→科技暴跌后红利被错杀=黄金坑加仓；科技大涨前提前降低风险敞口

### 网格化波动降本

核心逻辑：通过波动持续降低持仓成本，将成本股息率从4-5%提升到7-8%。

1. 每次回调都是降本机会——股息率高于持仓成本股息率时加仓
2. 1-2年低吸+网格→成本股息率质变
3. 网格卖出只是降本手段，底仓始终保留收息
4. 卖出不是目的，"想亏钱都难"才是

## 分红复投策略

### 复投时机

- 6-8月分红高峰为主要复投窗口
- 一年两次分红的银行增加复投节点
- 避免在股权登记日前追高（除息后股价自然回落）
- **等更好机会**：分红到账≠立刻复投——如当前股息率偏低，持币等回调再出手

### 仓位管理

- 单只 ≤20%，行业 ≥3个
- 银行板块 40-60%
- 保留10-20%现金应对波动

### 估值参考

- 银行：PB<0.8为低估
- PE<6配合高股息率时性价比较好
- 股息率>8%异常高——往往不可持续

### 关键监控指标

| 指标 | 关注阈值 | 说明 |
|------|---------|------|
| 静态股息率 | ≥3.5% | 低于则考虑调仓 |
| 分红比例 | 30%-70% | 超出需分析原因 |
| 每股分红趋势 | 不下滑 | 下滑判断一次性or趋势性 |
| ROE | ≥10% | 盈利能力 |
| 核心一级资本充足率(银行) | ≥8.5% | 限制分红能力 |
| 不良贷款率(银行) | ≤1.5% | 资产质量恶化信号 |
| PB(银行) | ≤1.0 | 关注趋势而非绝对值 |
| 经营性现金流/净利润 | ≥0.8 | 利润含金量 |

## 网格化投资策略（股息率网格）

基于**静态股息率**替代股价作为网格切分标准。

### 为什么用股息率而不用股价？

| 维度 | 股价网格 | 股息率网格 |
|------|---------|-----------|
| 锚定物 | 绝对价格 | DPS（每股分红） |
| DPS变动时 | 网格失效 | 自动校准 |
| 价值锚 | 无 | DPS代表真实现金回报 |

### 网格参数

- 区间：3.0-6.0%，间距0.5%
- 卖出区：<4.0% → 买入区：≥4.5% → 持有区：4.0-4.5%
- 目标股价 = DPS / 目标股息率

### 金字塔仓位分配

| 股息率 | 仓位占比 | 逻辑 |
|--------|---------|------|
| 4.0% | 10% | 基准 |
| 4.5% | 15% | 合理低估 |
| 5.0% | 20% | 显著低估 |
| 5.5% | 25% | 市场恐慌 |
| 6.0% | 30% | 极端低估，满仓 |

### 执行纪律

1. 触发即执行——不纠结"还会不会跌/涨"
2. 卖出触发线主要作为**停止新增买入**的信号
3. 每年4月底年报出齐后重新计算所有银行网格线
4. 分红现金优先投向买入区的标的

### 多股票资金分配

两层策略：
- **第一层（跨股票）**：等权/股息率加权/等权+区域调整
- **第二层（单股票内）**：按金字塔比例分配

预留资金放入货基/国债逆回购，触发买入时T+0/T+1取出。

## 打新策略

打新是攒股收息的**辅助加速器**——用利润反哺红利底仓，不把打新当主业。

### 核心逻辑

- 打新账户是**临时账户**，达成即清仓
- 利润**全部转入红利**（招行/平安等），不进消费、不进娱乐账户
- A股打新是政策红利，不参与白不参与

### 牛市vs熊市卖出策略

| 市场 | 策略 |
|------|------|
| **牛市** | 分批次卖出：开盘→首日冲高→第2-3天清仓。优质新股"开得不算高"可等冲高 |
| **熊市** | 开盘全清，不恋战 |

💡 案例：长鑫存储——合理估值2.5-4万亿(40-55元)，<40不卖，50冲高卖小部分等60+，60-70卖大部分，预计高点80-85。

### 打新纪律

1. 用闲钱——不影响红利底仓
2. 目标驱动——达成即清仓，不做长期持仓
3. 利润归位——必须转入红利账户
4. 缴款不忘记——T+2日16:00前留足资金
5. 沪市市值优先——巨无霸多在科创板，可适度换仓增大打新额度
6. 市值性价比——200万中一签赚2万≈增厚1%，但专门为大额打新配市值不一定划算

## 资产转换策略

💡 森哥展示了普通人将低效资产转换为红利股权的路径：

### 房地产 → 红利股权
- 老破小：租售比1-2%、流动性差、需维护
- 红利资产：股息率4-5%+、T+1变现、零维护
- 转换后：现金流翻2-3倍

### 科技/IPO利润 → 红利底仓
- 用娱乐账户（能亏完的钱）参与博弈
- 利润**全部**转入招行/平安等红利核心资产
- 底仓红利不动，博弈利润反哺

### 工资结余 → 红利定投
- 每月固定15-30%定投
- 年终奖在市场悲观时集中加码
- 分红专用账户隔离
